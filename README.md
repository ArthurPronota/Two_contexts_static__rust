# Два контекста `'static` в Rust

## Краткий ответ

**`'static`** встречается в **двух разных** контекстах:

| # | Контекст | Что означает | Пример |
|---|---|---|---|
| **1** | **Lifetime ссылок** | Ссылка **живёт всю программу** | `&'static str` |
| **2** | **Trait bound** | Тип **не содержит** короткоживущих ссылок | `T: 'static` |

**Путаница:** «`'static`» в **bound** **не** означает «значение живёт **вечно**». Оно означает «значение **не содержит** **короткоживущих** ссылок».

## Контекст 1: lifetime `'static` для ссылок

**`&'static T`** — ссылка на данные, **живущие всю программу**.

### Источники `'static`

#### 1. Строковые литералы

```rust
let s: &'static str = "abc";
```

- **`"abc"`** — **литерал** в **`.rodata`** (read-only data).
- Живёт **всю** программу.

#### 2. Глобальные `static`

```rust
static MAX_USERS: u32 = 100_000;
```

- **`static`** — **глобальная** переменная.
- Живёт **всю** программу.
- `&MAX_USERS` — `&'static u32`.

#### 3. `Box::leak`

```rust
let leaked: &'static mut String = Box::leak(
    Box::new(String::from("efj"))
);
```

- **`Box::leak`** — **утекает** память → `'static`.
- **`&'static mut String`** — **изменяемая** статическая ссылка.

### Пример в вашем коде

```rust
let s: &'static str = "abc";   // ← контекст 1
```

- **`s`** — `&'static str`.
- Данные **в бинарнике**.

```rust
let leaked: &'static mut String = Box::leak(
    Box::new(String::from("efj"))
);
```

- **`leaked`** — `&'static mut String`.
- Память **утекла** → **никогда** не освободится.
- **Опасно:** утечка памяти.

### `Box::leak` — что делает

```rust
pub fn leak<'a>(b: Box<T>) -> &'a mut T
where
    T: 'a,
```

- **Потребляет** `Box<T>`.
- **Забывает** о **владении**.
- Возвращает **`&'a mut T`**.
- Память **никогда** не **освободится** (утечка).

**Применение:**

- Глобальные **singleton**-объекты.
- **Конфигурация**, живущая **всю** программу.
- **Строки**, создаваемые **один раз**.

### Опасность

```rust
for i in 0..1_000_000 {
    Box::leak(Box::new(format!("data {}", i)));   // ❌ утечка 1M строк
}
```

**Утечка** памяти → **OOM**.

## Контекст 2: trait bound `T: 'static`

**`T: 'static`** — **тип `T` не содержит короткоживущих ссылок**.

### Что это **не** означает

```rust
fn foo<T: 'static>(x: T) { ... }
```

**Не** означает «`x` живёт вечно».

### Что это **означает**

> Если `T` содержит ссылки, они должны быть **`'static`**.

### Примеры

#### `String: 'static`

```rust
fn foo<T: 'static>(x: T) { }

foo(String::from("hello"));   // ✅
```

- **`String`** **владеет** данными.
- **Нет** ссылок внутри.
- ✅ `T: 'static`.

#### `&'static str: 'static`

```rust
foo("hello");   // ✅
```

- **`&'static str`** — **статическая** ссылка.
- ✅ `T: 'static`.

#### `&'a str` — **не** `'static`

```rust
let s = String::from("hello");
let r = &s;

foo(r);   // ❌ если 'a не 'static
```

**Ошибка:**

```
error[E0597]: `s` does not live long enough
```

**Причина:** `r` — `&'a str`, где `'a` — **короткий** lifetime.

#### `Box<&'a str>` — **не** `'static`

```rust
let s = String::from("hello");
let b = Box::new(&s);

foo(b);   // ❌
```

**Причина:** `Box<&'a str>` **содержит** короткоживущую ссылку.

### Важно: значение **можно** удалить

```rust
fn foo<T: 'static>(x: T) {
    drop(x);   // ✅ можно удалить
}

foo(String::from("hello"));   // ✅
```

**`T: 'static`** **не** запрещает **удаление** — только **короткоживущие** ссылки.

## Разбор вашего примера

### `spawn`

```rust
fn spawn<F: FnOnce() + 'static + Send>(f: F) {
    thread::spawn(move || {
        f();
    })
    .join()
    .unwrap();
}
```

**`F: 'static`** — **контекст 2** (trait bound):

- **Замыкание** **не содержит** короткоживущих ссылок.
- Может быть **перемещено** в **поток**.
- **Не** означает «живёт вечно».

### Вызов

```rust
let data = String::from("klm");

spawn(move || {
    println!("Get data: {data}");
});
```

- **`data`** — `String`, **владеет** данными.
- **`move`** — **перемещает** `data` в замыкание.
- **`String: 'static`** → ✅.

### Что было бы с `&data`

```rust
let data = String::from("klm");

spawn(move || {
    println!("Get data: {}", &data);   // ❌
});
```

**Ошибка:**

```
error[E0597]: `data` does not live long enough
```

**Причина:** `&data` — **короткоживущая** ссылка. **`thread::spawn`** требует **`'static`**.

### Решение

```rust
let data = String::from("klm");
let data = Box::leak(Box::new(data));   // &'static mut String

spawn(move || {
    println!("Get data: {}", data);   // ✅
});
```

**Утечка** → `'static` → ✅.

## Итог

- **`'static`** — **два разных** смысла:
  1. **Lifetime ссылок** — `&'static T` — **живёт всю** программу.
  2. **Trait bound** — `T: 'static` — **не содержит** коротких ссылок.
- **Контекст 1:** строковые **литералы**, `static`, `Box::leak`.
- **Контекст 2:** `String`, `Vec`, `Box<T>` — **владеют** данными.
- **`T: 'static`** **не** означает «живёт вечно».
- **`T: 'static`** означает «**нет** короткоживущих ссылок».
- **Удаление** возможно — `'static` **не** запрещает `drop`.
- **В вашем примере:**
  - `s: &'static str` — **контекст 1**;
  - `F: 'static` в `spawn` — **контекст 2**;
  - `Box::leak` — **утечка** → `'static`.
- **Правило:** `&'static T` — **живёт вечно**; `T: 'static` — **не содержит** коротких ссылок.
